This project is a simple brute-force search to find VLEA labelings of simple trees to help find patterns.  A vertex-labeled edge-antimagic (VLEA) 
labeling of a graph G is an assignment of the numbers 1 through n to the vertices in such a way that the induced edge sums are all distinct and
consecutive.  This code simply goes through every possible labeling looking for VLEA labelings.  Not much work was done to optimize the code.
